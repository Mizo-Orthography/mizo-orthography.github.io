# mizo-orthography.github.io

Collaborative repo for standardization of Mizo orthography.

## Mizo Orthography 2.0

This repo hosts the public proposal for **Mizo Orthography 2.0** — a small set
of accent marks that make Mizo's tone and vowel length visible in writing,
without changing the underlying alphabet.

**Read the full proposal, with old-vs-new comparisons and audio, on the live
site:** https://mizo-orthography.github.io
