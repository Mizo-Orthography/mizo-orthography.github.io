{%- comment -%} Renders a play button for assets/audio// if that file has been added to the repo, or a quiet "not recorded yet" marker otherwise. This means contributors can drop in a correctly-named clip and the site will pick it up automatically, without anyone editing index.md. Usage: {% include audio.html dir="alphabets" file=item.file label=item.symbol %} {%- endcomment -%} {%- assign clip_path = "/assets/audio/" | append: include.dir | append: "/" | append: include.file -%} {%- assign clip = site.static_files | where: "path", clip_path | first -%} {%- if clip -%} {%- else -%} 🔇 {%- endif -%}
